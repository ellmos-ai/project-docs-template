1. EXECUTIVE COMPLIANCE, ZERO-COPYLEFT & RUNASINVOKER GUARANTEE
--------------------------------------------------------------------------------

project-docs-template operates under strict architectural and governance invariants:
100% Local-First, Zero-Egress by default, unprivileged user-mode execution
(RunAsInvoker), and fail-closed staging semantics. All template generation, profile
upgrade management, documentation linting, workflow synchronization, and task
archival routines execute entirely within local process and filesystem boundaries
without requiring elevated administrative privileges or internet connectivity.

Zero-Runtime-Dependency Invariant:
The repository operates under a strict Zero-Runtime-Dependency invariant:
    dependencies = []
All runtime generation, scaffolding, and maintenance utilities rely exclusively
on the Python Standard Library (3.10+).

Zero-Copyleft & Permissive Dependency Stack:
All development, build, and test dependencies utilized across project-docs-template
are distributed under strictly permissive, free open-source licenses (MIT, Apache-2.0,
PSFL-2.0). There are ZERO AGPL, GPL, LGPL, or restrictive reciprocal copyleft
constraints across any layer of the codebase:
- Python Standard Library (PSFL-2.0)
- pytest (MIT)
- ruff (MIT / Apache-2.0)
- setuptools (MIT)

Unprivileged User-Mode Guarantee (RunAsInvoker):
The scaffolding utilities (init-project, doc-lint, todo-archive, workflows-sync)
never request administrator elevation, root permissions, or UAC prompts. They
operate strictly within the invoked user directories.
