# AGENTS.md — Redirect

Dieses Projekt nutzt **[`CLAUDE.md`](./CLAUDE.md)** als kanonische Instruktions-Datei für alle AI-Coding-Agenten (Claude Code, Codex, Cursor, Cline, Aider, Windsurf, Copilot, Antigravity/Gemini).

Der Inhalt ist **tool-agnostisch**. Der Dateiname ist Claude-Code-spezifisch nur deshalb, weil Claude Code die Datei automatisch in den Kontext lädt — dadurch entfällt ein extra Dateizugriff für das primäre Tool. Andere Agenten sollten **[`CLAUDE.md`](./CLAUDE.md)** direkt lesen und danach mit [`START.md`](./START.md), [`STATE.md`](./STATE.md) und [`TODO.md`](./TODO.md) fortfahren.

→ **Weiter zu [`CLAUDE.md`](./CLAUDE.md)**

---

**Warum diese Datei existiert:** Wenn du ein Agent-Tool nutzt, das `AGENTS.md` als Standard liest, landest du hier und wirst weitergeleitet. Single Source of Truth bleibt `CLAUDE.md` — keine Duplikation, kein Sync-Drift. Reine Lauf- und Prüfprotokolle gehören niemals in `AGENTS.md` oder `CLAUDE.md` (Protokolltrennung).
